# 집합건물 기준시가 — 독립 계산기

주소: `집합건물_기준시가.html`. 기존 `기준시가.html`, `arap_gijunsiga.js`, 저장 데이터 및 허브는 변경하지 않는다.

## 사용

1. 실제 평가기준일(2025 또는 2026년)과 호별 고시 여부를 선택한다.
2. 일괄고시 대상은 해당 호 전체 토지·건물 일괄가격을 직접 입력한다. 공동주택가격도 별도 선택한다. 고시 여부 자동 판정이나 홈택스 수집은 하지 않는다.
3. 일괄고시가 없는 비주거 집합건물은 지번주소 → 후보 주소 → 동 → 호를 선택한다. API에서 전유·공용부분, 구조, 신축연도, 해당 연도 공시지가를 가져온다. 용도 매핑은 사용자가 확인·수정한다.
4. **대지권은 API 조회 불가. 등기부를 보고 면적 또는 전체 필지면적 × 분자/분모를 직접 입력한다.** 건축 연면적 비율로 추정하지 않는다. 여러 필지는 각각 입력한다.
5. 공시지가의 공시 시점, 면적 및 지수를 확인한 후 결과를 확인하고 근거 복사 또는 인쇄/PDF를 사용한다.

## 두 기준의 구분

- 상증세법 시행령 제49조 제6항의 10억원 판단: **소득세법 제99조 기준시가**. 건물의 개별특성 조정률 및 상증용 대수선 할증 미적용. 전유·공용 합계에 구조·주용도별 단가 적용. 동일 구조·용도의 공용부분은 귀속 주용도를 적용한다.
- 상증세법 제61조의 보충적 평가 참고: 사용자가 검토·입력한 부분별 조정률 적용. 확인 전에는 결과를 표시하지 않는다. 감정기관 수 판단에는 사용하지 않는다.
- 고시가격 및 판단은 **호 전체 기준**. 일부 취득지분만큼 줄이지 않는다. 일괄가격에 토지를 중복 가산하지 않는다.
- 공동주택가격 미공시, 최초고시 전 환산, 무허가 증축 및 특수 평가 등은 별도 검토 대상이다.

근거: 국세청 「2026년 건물 기준시가 계산방법 해설」 본문 4~5쪽(산식 및 조정률 적용 구분), 구조·용도·위치지수 및 잔가율표. 2026년 고시번호는 **제2025-39호**이며, 원본 공유 엔진 주석의 제2026-39호와 구분한다.

## 파일과 검증

- `condo-standard-indices.js`: 기존 고시표의 독립 스냅샷. 원본 공유 엔진을 수정하거나 실행 상태를 공유하지 않는다.
- `condo-standard-price.js`: 입력 검증, 토지 비율, 호 전체 소득세법 기준, 선택적인 보충적 평가 계산.
- `condo-standard-ui.js`, `condo-standard-price.css`: 독립 UI와 조회. 새 대상 및 동·호 전환 시 이전 결과·대지권·확인 상태를 지운다. 비동기 조회의 이전 응답을 폐기한다.
- `node tests/condo-standard-price.cjs`: 가상 산술자료로 경계값·공용 포함·기준 분리·누락 차단·고시경로·공용 매핑·복수필지 검증.

고객 주소·등기부·소유자 데이터는 테스트/예시로 포함하지 않는다. 사용자 입력값을 서버나 기존 앱 저장키에 저장하지 않는다. 주소 조회는 기존 도구와 동일한 V-World 및 건축HUB 프록시를 사용한다. 로컬 개발 Origin은 프록시 CORS 허용 대상이 아니므로 API 실조회는 배포된 GitHub Pages Origin에서 확인한다.
