# 결정기록 (ADR-lite)

> 코드와 PR은 "무엇이 바뀌었나"를 남기지만 "왜 그렇게 정했나, 무엇을 기각했나"는 남기지 않는다.
> 이 파일은 그 빈칸을 메운다. **Claude가 PR을 머지할 때마다 그 세션에서 내린 결정을 여기에 추가한다**(CLAUDE.md 3번 원칙).
> 사용자는 따로 쓰지 않는다. 한 결정에 두세 줄. 형식: 날짜 · 결정 · 이유 · 기각한 대안(있으면) · 관련 PR.
> 새 세션의 Claude는 같은 질문을 다시 묻기 전에 이 파일을 먼저 읽는다.

## 2026-09-04 · 토지건물 (공시지가기준법·거래사례비교법)

- **칸 색은 "여기서 고칠 수 있느냐"로만 나눈다.** 노랑 = 평가사가 정하는 값, 연한 회색 = 자동이지만 직접 고칠 수 있음(고치면 파란/빨간 글씨), 진한 회색 = 자동이고 고칠 수 없음(개별요인 '계' 등). 패널 종류로 색을 다르게 하지 않는다. *기각*: 시산가액 패널만 연하게 두자는 안 — 규칙이 깨져 사용자가 클릭해 보게 됨. 시산가액 패널 등 다른 고정 칸에 진한 회색을 확대 적용하는 건 **보류**(사용자 판단 대기). PR #85 #94
- **그 밖의 요인 표의 자동 칸은 전부 직접 수정 가능.** 값이 자동계산과 다르면 빨간 글씨 + 경고띠 + 「↺ 원래대로 복원」. 수정값은 표준지별 `STDS[j].etcOvr`에 저장. 아래 개별요인비교치 '계'는 항상 자동값으로 두어 비교 기준 역할. PR #85
- **시점수정은 사례 기준으로 계산한다.** 지역·용도는 본건이 아니라 선택한 사례의 소재지·용도지역. 지가변동률 자동조회를 먼저 누르지 않아도 사례를 고르면 표를 스스로 준비해 계산. 각주에 근거를 남긴다: `1.00443 — 서울 중랑구 (26.01.31~26.04.14) (주거지역)`. PR #88
- **사례 소재지에 시군구가 없으면("상봉동 74-6") 주소 조회로 시군구를 찾는다.** 후보가 여럿이면 본건과 같은 시·도 우선, 못 찾으면 본건 시군구. **"(추정)" 같은 라벨은 붙이지 않는다** — 사용자는 당연히 본건 근처 사례를 넣고, 잡다한 표시는 원치 않음. 접미사를 뗀 한 글자 조각(동구→동)은 매칭에서 무시(상봉동이 대전 동구로 잡히던 오류). PR #91
- **시점수정치 조회는 사례를 "선정"할 때만.** 결과는 사례 객체(`timeMeta`)에 저장돼 다른 사례로 옮겨 다녀도 계속 보이고, 같은 기간이면 재선정 시 재조회 없음. ↻ 버튼만 강제 재조회. 거래일자·소재지·용도지역을 고치면 그 사례 값만 지움. *기각*: 그 밖의 요인 탭에 로딩 표시만 넣는 A안 — 거래사례 탭에서 선정하면 아무것도 안 보임. PR #89
- **거래사례 표에 '시점수정치' 행을 두고, 평가사례 표에는 (일단) 열을 두지 않는다.** 사용자가 "안 붙여도 될 듯"으로 보류. 단, 같은 개념은 같은 자리에 두는 것이 맞으므로 **통일 방향(평가사례에도 숫자 굵게 + 근거 작은 글씨로 압축한 열)을 제안한 상태**. 다음에 붙일 때는 이 형식으로. PR #89 #98
- **거래사례비교법 시점수정은 거래사례 표에서 계산해 둔 값을 끌어온다.** 탭을 열 때 칸이 비어 있으면 채우고, 손으로 적은 값은 덮지 않는다. 채택을 바꾸면 항상 그 사례 값으로. 보정표 아래 근거줄 + ↻ 버튼. PR #96
- **공시지가기준법 시산가액 카드는 왼쪽 열(개별요인비교 아래).** 거래사례비교법 탭과 같은 구조로 맞춤. 11칸이라 왼쪽 열에서는 옆으로 스크롤됨(면적·시산가액만 남기는 축약은 미결). PR #96
- **거래사례 ✕(비우기/삭제)는 실행취소가 있어야 한다.** 복구 버튼은 안내줄이 아니라 **지운 열 머리글의 ✕ 옆 ↩**. 여러 번 누적, 선정·채택 상태도 함께 복원, 새로고침하면 사라짐. *기각*: 안내줄의 「↩ 복구」 버튼 — 사용자가 ✕ 옆을 원함. PR #96 #98
- **평가사례도 거래사례처럼 행마다 붙여넣기 칸(kapa hub).** 상단 큰 붙여넣기 상자는 없앰. 붙이면 그 행부터 채우고 여러 건은 아래 행으로. 기본 빈 3행, ✕는 3행까지 비우기. PR #97
- **예시 회색글씨(placeholder)는 본건 토지가 조회되면 전부 숨긴다.** "예: 안양시 동안구 …" 같은 예시가 실제 물건(상봉동)과 달라 혼란을 줌. '-'·'반올림'·'kais붙여넣기'·'⏳ 계산 중…' 같은 형식 안내만 남김. 본건이 비면 복원. PR #91
- **배경 조회(사례 시군구 확인)는 수동 붙여넣기 단계(tryManual)를 쓰지 않는다.** 사용자가 누르지 않은 작업이 창을 띄우면 안 됨. 실패하면 조용히 대체값. PR #91
- **두 세션이 같은 파일의 같은 함수를 동시에 고치지 않는다.** 오늘 그 밖의 요인 `calcGongsi`를 두 세션이 건드려 충돌 위험. 영역을 나누거나, 먼저 끝난 쪽을 머지한 뒤 다음 세션에 "main 최신 반영" 지시.
