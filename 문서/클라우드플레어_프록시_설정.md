# 클라우드플레어 프록시 설정 (약 15분, 무료)

토지건물 앱의 **건축물대장 자동조회**(그리고 나중에 지가변동률)는
브라우저가 공공데이터포털을 직접 못 불러서(CORS 차단) **중계 서버**가 필요합니다.
그 서버 코드가 `문서/클라우드플레어_프록시.js`이고, 클라우드플레어 Workers(무료)에 올립니다.

> 구글 앱스 스크립트(관리자 수신함) 세팅과 비슷한 난이도입니다. 붙여넣기만 하면 됩니다.

---

## 1. 계정 만들기 (처음 1회)

1. https://dash.cloudflare.com/sign-up 접속 → 이메일로 가입 (무료 플랜 그대로)
2. 로그인 후 왼쪽 메뉴 **Workers & Pages** 클릭

## 2. Worker 만들기

1. **Create** 버튼 → **Create Worker**
2. 이름을 `ongyeol-proxy` 로 바꾸고 → **Deploy** (일단 기본 코드로 배포됨)
3. 배포되면 **Edit code** 클릭
4. 편집기에 있는 내용을 **전부 지우고**, 저장소의 `문서/클라우드플레어_프록시.js` 내용을 **그대로 붙여넣기**
5. 오른쪽 위 **Deploy** 클릭

## 3. API 키 넣기 (환경변수)

1. Worker 화면에서 **Settings** 탭 → **Variables and Secrets** → **Add**
2. 다음을 추가:
   - Type: **Secret**, 이름: `DATAGO_KEY`
     값: 공공데이터포털 마이페이지의 **일반 인증키** 문자열 그대로
     (예: `gmQSMNpJ...%2BdL8qvs...%3D%3D` — %2B 같은 게 섞인 형태면 그 형태 그대로)
   - (나중에 지가변동률 붙일 때) Type: **Secret**, 이름: `RONE_KEY`, 값: 부동산원 R-ONE 키
3. **Deploy** (변수 저장 후 재배포)

## 4. 주소 확인 & 점검

1. Worker 첫 화면에 **`https://ongyeol-proxy.<계정명>.workers.dev`** 형태의 주소가 보입니다. 이걸 복사.
2. 브라우저에서 그 주소를 열었을 때 아래처럼 나오면 성공:
   ```json
   { "ok": true, "service": "ongyeol-proxy", ... }
   ```
3. 건축물대장 점검: 주소 뒤에 `/bld?pnu=4117310200114430005` 붙여 열기
   → 층별 데이터(JSON)가 주르륵 나오면 완성.

## 5. 앱에 주소 연결

복사한 Worker 주소를 개발자(Claude)에게 알려주면
`토지건물.html`의 `PROXY_BASE` 값에 넣어 연결합니다. 그 후에는:
- 건축물대장 자동조회가 **수동 붙여넣기 없이** 바로 됩니다.
- 지가변동률(R-ONE)도 같은 서버로 자동화할 수 있습니다.

---

## 6. 재배포 — 프록시 코드가 바뀌었을 때 (약 3분)

저장소의 `문서/클라우드플레어_프록시.js`가 바뀌면 클라우드플레어에 다시 붙여넣어야 적용됩니다.
(2026-09-04 2판: 건축물대장 조회의 **집합건물 호별 전유면적**이 이 판부터 됩니다. 구판이면 화면에 "프록시가 구버전입니다" 경고가 뜹니다.)

1. https://dash.cloudflare.com 로그인 → 왼쪽 **Workers & Pages** → 목록에서 **ongyeol-proxy** 클릭
2. 오른쪽 위(또는 상단) **Edit code** 클릭 → 편집기가 열림
3. 편집기 안을 클릭하고 **Ctrl+A → Delete** 로 전부 지움
4. 깃허브에서 `문서/클라우드플레어_프록시.js` 를 열어 **Raw** 버튼 → **Ctrl+A → Ctrl+C** 로 전부 복사 → 편집기에 **Ctrl+V**
   (깃허브 주소: https://github.com/wjjung111/ongyeol/blob/main/문서/클라우드플레어_프록시.js)
5. 오른쪽 위 **Deploy** 클릭 → "Deployed" 표시가 뜨면 끝. (API 키 환경변수는 그대로 남아 있으니 다시 넣지 않아도 됩니다)
6. 확인: 브라우저에서 `https://ongyeol-proxy.woojin-apr.workers.dev` 를 열었을 때 `"ver":2` 가 보이면 새 판입니다.
   그리고 건축물대장 조회에서 "서대문구 홍제동 455" → 101동 → 102호를 고르면 전유 84.96㎡가 나오면 성공.

## 문제 해결

| 증상 | 원인/조치 |
|---|---|
| `{"error":"서버에 DATAGO_KEY 미설정"}` | 3번 환경변수 추가 후 Deploy 안 함 → 다시 Deploy |
| 층별 데이터가 빈 값 | 해당 지번에 대장이 없거나 PNU 오류 — 다른 지번으로 시험 |
| 앱에서 여전히 수동 창 | 앱에 PROXY_BASE 연결 전 — 5번 단계 진행 |
| 건축물대장 호별 전유면적에 "프록시가 구버전입니다" | 6번 재배포를 안 했거나 옛 코드를 붙여넣음 — Raw 화면에서 전부 복사했는지 확인 후 다시 Deploy |

**보안 메모**: 키는 Worker 안(Secret)에만 있고 페이지·저장소에 노출되지 않습니다.
허용 출처는 `wjjung111.github.io`로 제한되어 다른 사이트에서는 이 프록시를 못 씁니다.
