# 입주권.html 개발노트 (Cloud → 로컬 Claude Code 인계)

> 온결 입주권 감정평가 자동화 앱(`입주권.html`) 1차 개발 완료. hwpx 시각검증만 로컬(한글) 몫.
> 근거: `문서`가 아닌 업로드 핸드오버(`입주권_자동화_핸드오버_Cloud.md`) + 토큰화템플릿 5종.

## 1. 무엇을 만들었나
- **`입주권.html`** 신설 — 집합건물 "여러 호수" 화면을 계승한 단일 React 앱.
  - 검증된 엔진·유틸(hwpx `buildTokenHwpx`+파랑→검정, 청구서 `parseFeeStatement`/`computeCheonggu`,
    시점수정 R-ONE 자동계산 `SijeomModal`, `numberToKoreanMoney`, ZIP 엔진)은 **집합건물.html에서 그대로 발췌**.
  - 입력폼(①대상물건개요=사업·조합+본건 가·나+분담금통지서 / ②접수개요 / ③사례 등 입력 / ④가격산출),
    계산엔진(§3), 토큰맵 빌더(`buildIpjMap`), 5종 다운로드 + 청구서, 방배 샘플은 신규 작성.
- `index.html` 허브에 **🎫 EXACT 입주권**(베타) 버튼 추가.

## 2. 코드로 검증된 것 (한글 없이 확인 가능한 전부)
- **골든테스트 통과**: 방배 샘플 → 입주권 감정평가액 **6,313,565,001원** (중간값 전부 핸드오버 표와 일치).
  - 가 결정단가 40,000,000 / 아파트감정가 2,394,000,000 / 프리미엄 1,337,100,000
  - 나 결정단가 34,400,000 / 아파트감정가 3,951,000,000 / 프리미엄 2,242,650,000
  - 아파트감정가합 6,345,000,000 · 프리미엄합 3,579,750,000 · 권리가액 2,733,815,001
- **토큰 139종 전부 치환**: 5개 템플릿 각각 미치환 `{{토큰}}` 0개, **잔여 파랑 charPr 0개**, mimetype 선두, ZIP 무결성 OK.
- 랜드마인 반영: 아파트감정가 = **결정단가 기준** 백만반올림(산정단가 아님), 결정단가 십만반올림.

## 3. 로컬(한글)에서 확인해야 할 것 ★
1. 5종 hwpx를 **한글로 열어** 표 깨짐·겹침(linesegarray) 없는지, 값이 올바른 셀에 들어갔는지.
2. 특히 **명세표** 셀 대응: `{{가_동}}`(=동), `{{가_층호}}`(=호), `{{가_대지지분}}`, `{{시군구}}/{{법정동}}/{{지번}}` 위치.
3. **의견서** 시점수정표의 지역경로가 `"서울 > 강남지역 > 동남권 > {{시점_지역}}"`로 **템플릿에 반쯤 하드코딩**됨 →
   방배(서초구)는 정상, 타지역 건이면 앞부분도 토큰화 필요.
4. 청구서는 집합건물 엔진·템플릿 그대로 재사용 — 수수료 계산서 붙여넣기 동작 동일한지.

## 4. 이번 버전에서 뺀 것 / 사용자 결정사항
- **평가전례 표**: 사용자와 "지금은 빼고 개발"로 합의 → 미포함. (추후 의견서 템플릿에 표 추가 시 배선 준비돼 있음: `buildIpjMap`에 슬롯만 추가하면 됨.)
- **공부서류 업로드/자동인식(PDF)**: 입주권은 불필요 → 제외(직접 입력).
- **조감도 이미지**: 방배 조감도 자리표시자 유지, 사업 바뀌면 한글에서 직접 교체(사용자 결정).
- **본건 호수**: 2호수(가·나) 고정. 1호수 단독 건은 후속.

## 5. 앱 내부 메모
- 저장키: `ipj:case-list`, `ipj:case:<접수번호>` (집합건물 `v2:*`와 분리 — 충돌 없음).
- 방배 샘플키 `SAMPLE-디에이치방배`(실접수번호 충돌 방지), 표시접수번호 `caseNoDisplay`, `_sampleVer`로 자동갱신.
- 선정 슬롯 규칙: 가=㉠=사례1, 나=㉣=사례4 (`buildIpjMap`이 선택 사례를 해당 슬롯에 자동 배치).
- 재조립 스크립트(개발 세션 scratchpad): `build_ipj.py`(발췌+템플릿 base64 주입), `harness.js`(엔진 골든/토큰 검증).
