# 관리자 수신함(구글 앱스 스크립트) 설정

관리자.html이 보여주는 사용 기록은 **구글 시트**에 쌓입니다.
그 시트에 기록을 받아 적는 프로그램이 "수신함"(앱스 스크립트)이고, 원본 코드는 `문서/관리자_수신함.gs`입니다.

> 수신함은 관리자 개인 구글 계정 안에 있습니다. 저장소에는 **코드만** 보관하고 비밀번호·데이터는 두지 않습니다.

---

## 1. 왜 기록이 0건이었나 (2026-08-03 조치)

- 관리자.html에서 **조회는 됐습니다** — 비밀번호가 통과하고 표가 그려졌으니 수신함·주소·권한은 정상.
- 그런데 시트에 데이터가 **한 줄도 없었습니다.** 즉 읽기는 되는데 **쓰기가 안 되던** 상태.
- 원인은 앱의 전송 방식이었습니다.
  - 앱이 `POST` + `mode:"no-cors"`로 보내서 **수신함이 거부해도 앱은 알 수 없었음** (성공과 실패가 똑같이 보임).
  - 게다가 **보내기 전에 "보냄" 표시를 먼저 찍어놔서**, 실패한 건은 다시 시도조차 안 됐음.
  - 수신함에 `doPost`가 없거나 오류가 나도 며칠이고 조용히 지나갔던 이유입니다.
- 조치: 전송을 **GET(쿼리스트링) 방식**으로 바꿔 응답을 읽고, **수신 확인된 건만** "보냄" 처리하고, 못 보낸 건은 대기줄에 남겨 다음 접속 때 재전송합니다.

---

## 2. 설치 (3분)

1. 기록이 쌓일 **구글 시트**를 엽니다. (이미 쓰던 시트가 있으면 그걸 사용)
2. 상단 메뉴 **확장 프로그램 → Apps Script**.
3. 편집기에 있는 내용을 **전부 지우고**, `문서/관리자_수신함.gs` 내용을 **그대로 붙여넣기** → 저장.
4. 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성** → **속성 추가**
   - 속성: `ADMIN_PW`
   - 값: 관리자.html에서 쓸 **비밀번호** — **지금까지 쓰던 그 비밀번호를 그대로** 넣으면 됩니다.
   - 저장.
5. 오른쪽 위 **배포 → 새 배포** (또는 기존 배포 → 연필 아이콘 → **새 버전**)
   - 유형: **웹 앱**
   - 실행 사용자: **나**
   - **액세스 권한: 모든 사용자** ← ★ 이게 "Google 계정이 있는 모든 사용자"나 "나만"이면 다른 평가사들이 보낸 기록이 전부 막힙니다.
   - 배포 → 승인 요청이 뜨면 허용.
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

### 주소가 바뀐 경우에만
새로 배포해서 URL이 달라졌다면 저장소의 두 곳을 같은 주소로 바꿔야 합니다.
- `집합건물.html` — `window.ARAP_USAGE_URL=` 줄
- `관리자.html` — `const URL_=` 줄

> **기존 배포에 "새 버전"으로 덮어쓰면 주소가 그대로**라 코드를 안 고쳐도 됩니다. 이 방법을 권합니다.

---

## 3. 확인

1. 관리자.html 접속 → **연결 점검** 클릭
   - `✅ 수신함 정상 · 시트에 쌓인 기록 N건` → 수신함 OK
   - `⚠️ 점검에 응답하지 않음` → 스크립트가 구버전. 2번 과정으로 코드 교체 후 **새 버전** 배포
   - `❌ 연결 자체가 안 됨` → 배포 주소가 틀렸거나 액세스 권한이 "모든 사용자"가 아님
2. 집합건물 앱을 **새로고침**하고 건을 하나 저장 → 10초쯤 뒤 관리자.html **새로고침**
3. 과거 기록: 각 사용자가 앱에 접속만 하면, 그 브라우저에 저장돼 있던 건들이 **자동으로 한 번 일괄 전송**됩니다(백필 v2). 사용자가 따로 할 일은 없습니다.

---

## 4. 시트 열 구성

### '기록' 탭 (집합건물·입주권 앱의 건 요약)

> 실제 시트의 탭 이름이 `시트1`이어도 됩니다. '기록' 탭이 없으면 '접속' 탭을 뺀 나머지 탭이 하나뿐일 때 그 탭을 그대로 씁니다. 머리글 줄이 없어도 관리자.html이 알아서 처리합니다.

| 시각 | 사용자 | 접수번호 | 물건 | 유형 | 시산가액 | 동작 |
|---|---|---|---|---|---|---|

`동작` 값: `저장` / `감정평가서` / `청구서` / `과거건`(백필)

샘플 건(`SAMPLE-*`)은 앱·수신함 양쪽에서 제외됩니다.

### '접속' 탭 (시점수정 페이지 접속 기록 — 2026-09-02 추가)

| 시각 | 사용자 | 페이지 | 동작 | 기기 | 브라우저 | IP | 지역 | 통신사 | 상세 |
|---|---|---|---|---|---|---|---|---|---|

- `동작`: `접속`(페이지 열림) / `계산`(시점수정치 계산 버튼). `상세`에 유형·지역·기간·결과치.
- `사용자`: 시점수정 첫 화면에서 적은 이름(집합건물·입주권 앱에서 고른 이름과 같은 저장값). 이름 입력 기능 이전의 옛 기록은 `(이름 미등록)`.
- `IP`·`지역`·`통신사`: 앱스 스크립트는 접속자 IP를 알 수 없어서, **브라우저가 IP 조회 서비스(ipwho.is, 실패 시 ipapi.co)에 물어본 값**을 함께 보냅니다. 통신사 기준이라 시·구 단위까지만 맞고, 휴대폰 데이터는 통신사 소재지로 잡힐 수 있습니다. 둘 다 실패하면 `확인 실패`.
- 관리자.html **📈 시점수정 접속** 탭에서 봅니다. 탭에 "수신함이 구버전" 경고가 뜨면 아래 5번 절차로 새 버전 배포.

---

## 5. 접속 기록을 켜려면 (수신함 새 버전 배포 — 1분)

'접속' 탭은 수신함 코드가 새 버전이어야 쌓입니다. 주소는 그대로 두고 코드만 바꾸면 됩니다.

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. 편집기 내용을 전부 지우고 `문서/관리자_수신함.gs`를 붙여넣기 → 저장
3. **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**
4. 관리자.html **연결 점검** → `시점수정 접속 N건`이 같이 나오면 완료
