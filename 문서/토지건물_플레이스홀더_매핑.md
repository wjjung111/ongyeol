# 토지건물(토건) 감정평가서 플레이스홀더 매핑

> 대상 문서 3종의 `{{토큰}}` 설계서. 집합건물 v2.0 매핑(`의견서v2.0_플레이스홀더_매핑.md`)과 같은 방식.
> 최초 작성: 2026-09-09 (Claude). 근거 샘플: 아래 "샘플 출처" 참조.

## 0. 개요·원칙

- **대상 문서 3종**
  1. **의견서(산출근거)** = 「감정평가액의 산출근거 및 결정의견」 — 가장 복잡(Ⅰ~Ⅴ, 반복표 다수)
  2. **괄감** = 「(부동산)감정평가표」 — 표지 다음 1페이지 표
  3. **명세표** = 「(부동산)감정평가 명세표」 — 물건별 내역 표(현재 엑셀 양식)
- **치환 방식**: 템플릿 hwpx 안 `{{토큰}}` 문자열을 앱이 값으로 치환. 토큰은 **파란색**으로 표시해두고 채운 뒤에도 파란색 유지(집합건물 v2 최종 방침과 동일 — 필요시 검정 복귀도 가능).
- **값의 성격 2가지** (토건 앱 색 규칙과 동일)
  - **앱계산·자동조회 값** → 토큰(자동 치환). 이 문서가 다루는 대상.
  - **평가사 판단 문구**(개별요인 우열 설명·사례채택 이유 등 산문) → **자동화 제외**. 템플릿에 편집 가능한 일반 텍스트로 두거나 별도 "의견" 토큰으로 두되 앱이 값을 강제하지 않음. 아래 표에서 `판단` 표시.
- **반복행 표**: 필지·건물동·비교표준지·평가사례·건물층 등은 건마다 개수가 달라짐 → **행복제** 필요(§4 결정사항 참조). 거래사례는 3열 고정 표.

### 🔴 빨강 지침 해석 시 주의 (객관적 검토)
- red 파일은 매 건 바뀌는 값을 **매우 체계적으로** 표시함. 이 문서의 의견서 토큰은 red를 1차 근거로 함.
- 다만 **비교표준지 공시지가 표**(소재지·지번·면적·지목·용도지역·형상·공시지가·이용상황·도로교통·지세)는 red 미표시. 자동조회(V-World) 값이라 지침에서 빠진 것으로 판단 → **토큰에는 포함**하되 `※red미표시` 플래그. 발송 전 확인 대상.
- 의견 문구는 red가 일부만 칠해져 있음(거래사례비교법 개별요인 의견 1곳만 빨강). **일관되게 전부 판단(자유 텍스트)** 로 처리 권장.

## 1. 의견서(산출근거) 토큰

> ✅ **템플릿 제작 완료**: `템플릿/토건 의견서(산출근거) 템플릿.hwpx` (2026-09-09). **기준 샘플은 케이스 B(신사동 v2.hwpx)** — 앱 데이터모델(APPRS 8열: 기호·소재지·용도지역·지목·이용상황·사례단가·기준시점·평가목적 등)과 표 구조가 일치하기 때문(대구 red의 평가사례 면적·감정액 열은 앱에 없음). 값 375칸을 `{{토큰}}`으로 치환(토큰 251종), **FORMULA 필드 9쌍 제거**(개별요인 계·시산가액·건물합계·최종합계), 값셀 linesegarray 제거. 아래 표의 샘플값(케이스 C)과 토큰명은 그대로 유효.
> - **반복 표는 샘플 개수만큼 고정 토큰**: 거래사례 3열(`거래1~3_*`), 평가사례 3행(`평사1~3_*`), 건물층 5행(`층1~5_*`). 필지·표준지는 1행(단일 토큰). 실제 건이 이보다 많으면 **행복제 엔진 필요**(다음 단계·§4).
> - 도로교통은 대상토지 표에서 2칸(`토지_도로`+`토지_교통`), 표준지 표에서 1칸(`표준지_도로교통`) — 양식 그대로.
> - 감정평가액=합계=토지+건물. 공시 시산가액=토지감정평가액(합리성검토상 공시지가기준법 채택).
> - 원본 샘플의 '헙계'(합계 오타)는 라벨이라 그대로 둠 — 필요 시 별도 교정.
> - **한글에서 열어 렌더링 확인 필요**(코드검증만 통과).
