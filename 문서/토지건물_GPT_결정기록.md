# 토지건물 GPT 전용 결정기록

## 2026-09-16

- 사용자 요청: 원본 HTML·공용 JS·템플릿을 수정하지 않고 `토지건물_GPT.HTML`과 GPT 전용 파일만 추가한다. GPT 작업 브랜치에서 PR 후 main에 머지한다.
- 주 메뉴 8개: 대상물건 개요 / 토지평가 / 건물평가 / 토지건물 평가액 결정 / 위치도 / 요항표 / 감정평가서 다운로드 / 청구서 다운로드. 토지평가 아래 공시지가기준법·거래사례비교법·토지평가액 결정을 배치하고 마지막 선택을 유지한다.
- 문서 생성 카드는 기존 DOM ID·이벤트·숨김 필드를 보존하여 다운로드 패널로 이동한다. 계산식, 조회, 요항표, 청구서, 템플릿 생성 코드는 원본 그대로 유지한다.
- GPT 저장키만 `tojigeonmul-gpt-`로 분리한다. 최초 접속 때 기존 `tojigeonmul-` 자료를 읽어 복사하되 원본과 이미 존재하는 GPT 자료는 수정하지 않는다. 이후 두 버전은 독립 저장한다. 복사 실패 시 이번 복사만 되돌리고 안내한다. 인증과 공용 지가변동률 캐시는 기존대로 사용한다.
- 공용 파일은 수정 없이 참조한다. 향후 변경이 필요하면 GPT 전용 복사본을 먼저 만들어 연결한다.

## 검증

- `tests/toji_gpt.cjs`: 격리한 로컬 Chromium(Edge)에서 전체 메뉴 이동, 기존 ID 보존, 단일·복수 필지 계산 원본 일치, 저장·복원·새 평가서 및 메모 분리 확인.
- 토건 표지·괄감·의견서·명세표·요항표와 청구서 6종을 실제 다운로드하고 각 ZIP 안 XML이 원본 페이지 출력과 완전히 동일한지 비교한다. 실제 한글 앱에서의 열기·인쇄 배치는 미검증이다.
- 지도 탭 진입 시 기존 mapOpen 호출은 확인하되 지도 외부 API의 정확성·가용성은 이번 로컬 테스트 범위 밖이다.
