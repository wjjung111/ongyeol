# Ongyeol v1.0

온결 감정평가법인 — 집합건물 **감정평가서 · 청구서** 자동화 도구 (한글 `.hwpx` 출력).

> `wjjung111/woojin` 저장소의 EXACT 집합건물 v2.0을 **전용 저장소로 분리**한 것입니다.
> 감정평가서 산출근거·표지·감정평가표를 새 온결 양식(한글)으로, 청구서도 한글로 자동 생성합니다.

## 접속

- **웹**: https://wjjung111.github.io/ongyeol/  (GitHub Pages)
- 링크만 열면 **대표 샘플(압구정동 현대아파트 77동 904호, 접수번호 HI260709-2702)**이 자동으로 떠서 바로 체험 가능
- 각자 만든 평가건은 **각자 브라우저에만 저장**됨(서버 없음) — 서로 안 보임

## 주요 기능

| 단계 | 내용 |
|---|---|
| ① 대상물건개요 | 공부서류 PDF 자동인식(선택) · 물건정보 입력 |
| ② 접수개요 | 의뢰인·소유자·기준시점·여비·착수금·특별용역비 등 |
| ③ 사례 등 입력 | 거래사례·시점수정·가치형성요인 |
| ④ 가격산출 | **[3. 감정평가서(hwp)]** · **[1. 청구서(hwp)]** 한글파일 다운로드 |

- 감정평가서: 표지 + (구분건물)감정평가표 + 산출근거 및 결정의견 (플레이스홀더 129종)
- 청구서: 수수료 계산서 인식 + 착수금·특별용역비·여비 → 정산청구액까지 자동 계산

## 토지건물 (작업 중)

집합건물과 별개로 **토지건물 감정평가**(토지 공시지가기준법 + 건물 원가법 → 합산)를 준비 중입니다.

- **토지 조회 도구**: [`토지조회.html`](토지조회.html) — 지번 입력 → 토지특성·용도지역·공시지가 자동 조회(브이월드 API). 토지 산출의 입력자료 확보용. (https://wjjung111.github.io/ongyeol/토지조회.html)
- 다음 단계(예정): 토지 공시지가기준법·거래사례비교 + 건물 원가법 계산 엔진 → 토지건물 감정평가서·명세표 한글 출력. 참고 산출로직: `토지건물/토지건물_산출근거.xlsx`(woojin 저장소).

## 개발 / 배포

- 앱은 빌드 도구 없는 **단일 HTML**(React+Babel CDN). `index.html`이 곧 앱.
- 한글 템플릿은 `index.html`에 base64로 내장 — 런타임에 별도 로딩 안 함(`템플릿/`은 원본 보관용).
- **작업 = 새 브랜치 → 수정 → PR → main 머지.** main 머지 시 Pages 자동 재배포.
- 지수 자동계산 데이터(`arap_index_data.js`)는 `.github/workflows/update-index.yml`이 매일 06:00 KST 갱신.
  - ⚠️ 이 저장소 **Settings → Secrets → Actions에 `RONE_API_KEY`** 를 등록해야 워크플로우가 동작합니다(부동산원 R-ONE Open API 키). 없어도 앱은 정상 작동(지수 자동계산만 안내문구).

## 내부 식별자 (개명 금지)

localStorage 키(`appraisal-case-list`, `case:*`, `arap-*`), `arap_index_data.js`, `arap_launch.ps1`, `window.ARAP_INDEX_DATA`, `ArapSync` 등은 **절대 개명 금지** — 기존 사용자 저장 데이터·지수 연결이 끊어집니다. (표시 이름만 Ongyeol로 변경)
