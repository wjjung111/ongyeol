## 계산·XML 검사

`python tools/ipj_v1/test_engine.py`: 8개 테스트 통과.

- 독립적으로 정한 6종 기대값과 최종금액 일치.
- 기준시점 당일 포함, 이후 제외, 빈 납부내역 0, 환급금 차감.
- 배열 순서 대신 사례 ID 사용, 없는 ID와 다른 용도 차단.
- 직접결정단가의 근거 요구, 음수 프리미엄 유지.
- 통지 권리가액을 종전자산 × 비례율 값으로 덮어쓰지 않음.
- 지수·개별요인 곱과 정리 단위 계산 확인.
- 0 면적, 음수 분양가, 0 비교치, 잘못된 지분 차단.
- 미매핑/잔여 토큰 차단, ZIP mimetype 저장조건, 표 행수·셀 주소 확인.
- 물건별 평가 블록 안에서 다른 물건 값이 재반복되는 오류의 회귀 검사.
- 이미지 있는 출력에만 BinData 이미지가 포함되는지 확인.

## 한글 실제 출력 검사

Windows 한글 2024(13.0.0.3380)에서 6개 HWPX를 직접 열고 내장 PDF 저장으로 출력했습니다. 총 39페이지의 텍스트에서 잔여 토큰과 문자 깨짐이 없음을 확인했고, 페이지 이미지로 표 중복·페이지 넘김·이미지 삽입·지분 문단·하단 쪽번호를 확인했습니다. 혼합형 최종 결정 페이지는 확대 이미지로 별도 확인했습니다.

개발 중 복수물건 블록의 내부 표가 전체 물건 수만큼 다시 복제되는 문제가 발견되어 반복 문맥을 수정하고 전 유형을 재검증했습니다. 최종 파일에는 해당 중복이 없습니다.

## 한계 및 다음 연결

검증은 위 가상 입력 범위와 해당 한글 버전에 한정됩니다. 임의로 긴 실제 평가문구, 대량의 사진, 다른 한글 버전은 별도 확인해야 합니다. 법률문구·실제 거래사례·평가결론의 타당성을 검증한 자료가 아닙니다.

이 단계는 독립 의견서 템플릿과 참조 생성기입니다. `입주권v1.html` 화면과 브라우저 저장/출력 기능, 나머지 표지·괄호감정표·요항표·명세표는 아직 구현하지 않았습니다.
