# 토지건물 문서 연결 검증

집합건물 `s3r86w8a_test.html`의 `buildMyeongseCellMap`과 같은 셀 매핑 방식이다. 양식은 제공받은 엑셀의 B:J 열, 병합 머리글, 인쇄영역과 장식을 유지한다. 원본 사건 내용은 제거했다.

| 플레이스홀더 | 열 | 토지 | 건물 |
| --- | --- | --- | --- |
| 명세_기호 | B | 필지 번호 | 동 기호 |
| 명세_소재지 | C | 본건 소재지 | 건물 소재지, 없으면 첫 필지 소재지 |
| 명세_지번 | D | 본건 지번 | 건물 지번, 없으면 첫 필지 지번 |
| 명세_지목용도 | E | 지목 | 용도와 해당층 |
| 명세_지역구조 | F | 용도지역 | 구조 |
| 명세_공부면적 | G | 본건 면적 | 해당층 연면적 |
| 명세_사정면적 | H | 평가에 사용하는 면적 | 평가에 사용하는 연면적 |
| 명세_평가액 | I | 공시지가기준법 필지별 금액 | 직접 입력한 재조달원가를 반영한 층별 금액 |
| 명세_비고 | J | 본건 비고 | 건물 비고 |

현재 토지건물 평가에는 별도의 지분·제외면적 입력이 없으므로 공부·사정 면적은 같다. 원본 집합건물 예시의 지분 비율은 가져오지 않는다.

검증 절차:

1. 기존 의견서 테스트의 다필지 fixture(토지 2필지, 건물 7층)를 적용한다.
2. `ArapTojiDocuments.statementRows()`의 9행을 `buildStatement`로 출력한다. 같은 행을 3회 연결한 27행도 출력한다.
3. 엑셀 숫자 셀 9개/27개 및 합계가 각각 1,337,641,500 / 4,012,924,500인지 확인한다. 합계 수식, 인쇄영역 확장, 75.5㎡ 소수 표시, 기존 사건 내용 제거도 확인한다.
4. 요항표는 제공된 원본의 빨간색 실행 구간에서만 토큰을 치환한다. 검정 문구 전체가 원본과 동일한지, 미입력 빨간 토큰은 원래 표시로 남는지, 임의의 `[기입]`이 추가되지 않았는지 확인한다.
5. 거래사례비교법에서 비교사례 채택/필지별 요인이 좌우에 있고 시산가액은 하단 전체 너비인지 확인한다. 기존 공통 분할 핸들과 저장키를 사용한다.
