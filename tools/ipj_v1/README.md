# 입주권 v1 의견서 템플릿

새 입주권 앱의 첫 단계인 **의견서 템플릿과 데이터 계약**입니다. 기존 입주권 HTML, 기존 계산 코드, 저장 키 및 기존 템플릿을 참조하거나 수정하지 않습니다. 신규 앱 진입점은 이후 `입주권v1.html`로 만들 예정이며 이번 변경에는 앱 화면이 포함되지 않습니다.

## 사용

Python 3.10+, lxml, Pillow가 필요합니다. 저장소 루트에서 실행합니다.

```sh
python -m pip install -r tools/ipj_v1/requirements.txt
python tools/ipj_v1/build.py
python tools/ipj_v1/examples.py
python tools/ipj_v1/test_engine.py
python tools/ipj_v1/render.py tools/ipj_v1/fixtures/03_아파트2_상가1_청산금.json result.hwpx
```

- `템플릿/입주권v1/입주권v1_의견서.hwpx`: 파란색 토큰이 들어간 원본 템플릿
- `템플릿/입주권v1/플레이스홀더_매핑.md`, `placeholders.json`: 86개 바인딩의 원천·유형·위치·반복조건
- `템플릿/입주권v1/시험출력/`: 실제 고객정보가 없는 가상 시험출력 6종
- `engine.py`: 단일 계산 모델 → 템플릿 반복 확장 → 엄격 치환
- `blank.hwpx`: 이 작업에서 한글 2024로 새로 생성한 빈 문서의 구조 시드
- `picture.xml`: 새 시험 그림 문서에서 추출한 그림 요소 구조. 실제 사업 이미지 아님

템플릿을 직접 고친 경우 `build.py` 재실행은 템플릿을 재생성하므로 먼저 사본으로 저장하십시오. 반복 토큰은 한 `hp:t` 안에 유지합니다. 한글 편집으로 토큰이 여러 텍스트 노드에 나뉘면 지원하지 않으며 검증으로 걸러야 합니다.

## 데이터 원칙

입력 스키마의 실행 예시는 `fixtures/*.json`입니다. 공통 문장 및 사건정보는 `text`, 물건은 `units`, 사례는 `cases`, 납부·환급은 `transactions` 배열입니다. 물건별 `case_id`가 사례 ID를 참조하며, 배열의 첫 번째 사례로 자동 대체하지 않습니다. 개별요인은 물건별 배열로 주거/상가 항목을 다르게 구성합니다. 사례 가격은 총액, 면적은 전유면적(㎡), 비례율은 % 단위입니다.

1. 통지 권리가액을 원천값으로 유지합니다. 종전자산 × 비례율은 검산만 하며 차이를 표시합니다.
2. 납부와 환급 수령을 양수로 별도 입력합니다. 기준시점 당일까지 합산하고 이후 내역은 제외 표시합니다.
3. 배정물건 가액 합계 − 총분양가 = 프리미엄입니다. 음수도 허용합니다.
4. 권리가액 + 납부누계 − 환급수령누계 + 프리미엄 = 정리 전 전체 입주권 가액입니다.
5. 전체 가액 정리 후 지분을 곱하고 지분의 정리 기준을 별도로 적용합니다.
6. 정리 기준은 자릿수가 아닌 실제 원 단위 `quantum`과 `round`(반올림), `floor`(내림), `none`으로 명시합니다. Decimal로 계산하며 비교치 화면표시는 소수 6자리까지입니다. 화면표시 반올림 값으로 다시 계산하지 않습니다.
7. 직접 결정단가는 `unit_override`와 `override_reason`을 함께 입력해야 합니다. 단가 정리와 물건 금액 정리, 전체 금액 정리, 지분 정리를 분리합니다.
8. 지수 시점수정은 시작/종료 지수와 월·계열·출처를 보관합니다. 직접 시점수정치는 별도 근거 문장이 필요합니다. 법적 판단과 사례 선정 사유를 자동으로 확정하지 않습니다.
9. 조감도는 로컬 PNG/JPEG 파일을 HWPX 내부에 내장합니다. 가로세로 비율을 유지하고 본문 폭/최대 높이 내에 맞춥니다. 이미지 경로는 JSON에서 저장소 루트 기준 또는 절대경로입니다. 없어도 정상 출력됩니다.

미매핑 토큰은 조용히 빈칸으로 내보내지 않고 오류를 발생시킵니다. 필수 문장은 평가사가 완성해야 합니다. 선택 정보가 없으면 `-` 또는 부재 설명을 명시합니다. 동·호 미정은 배정 상태로 입력합니다. 출력 표와 최종 결정액은 같은 모델을 사용합니다.

## 검증과 범위

2026-09-18: 자동검사 8개 통과. 6개 시험출력을 한글 2024로 열고 PDF로 내보냈으며 각각 6/7/8/6/6/6페이지입니다. XML 치환뿐 아니라 복수물건 반복, 환급 차감, 지분 적용, 여섯 사례, 내장 이미지, 페이지 넘김을 확인했습니다. 검증 상세는 `템플릿/입주권v1/검증결과.md`에 기록합니다.

현재 Python 생성기는 차기 앱 연결을 위한 참조 구현입니다. 브라우저 생성기, 입력 UI, 사건 저장, 표지·괄호감정표·요항표·명세표는 다음 단계입니다. 임의 길이의 실사건 문장은 추가 편집이 필요할 수 있으며 모든 한글 버전과 모든 분량의 레이아웃을 검증한 것은 아닙니다. 실제 법률문구나 평가결론을 가상 시험자료에서 가져다 사용하면 안 됩니다.
