등기 간편열람

주소를 넣으면 내 PC의 에이전트가 인터넷등기소에서 선불(전자민원캐시)로 열람하고, PDF 저장과 함께 고유번호·전유면적·대지권을 뽑아 여기에 보여 줍니다.

    열람 요청

    주소를 치고 Enter → 토지 / 건물 / 토지+건물 중에 고릅니다. 동·호를 넣으면 집합건물(아파트·상가 호)로 바로 요청합니다.

    열람 수수료가 선불 잔액에서 바로 차감됩니다. 검색 결과가 정확히 1건 맞을 때만 자동 결제하고, 애매하면 PC에서 멈춰 확인합니다. 토지·건물은 같은 지번에 등기가 여러 개(예: 주1·주2)면 전부 한 건씩 받습니다.

    요청 목록

    고급: Apps Script 큐 (다른 기기에서 요청할 때만)

    비워 두면 이 PC의 에이전트(접수 창구 127.0.0.1:8790)로 바로 요청합니다 — 보통은 비워 두세요. 주소와 키는 이 브라우저에만 저장됩니다(공개 저장소 파일에는 넣지 않음).

    개인 전용 도구. 실제 열람은 본인 PC의 에이전트가 본인 등기소 계정·선불 잔액으로 합니다. 등기소 로그인(보안문자)은 PC에서 사람이 하고, 에이전트가 켜져 있는 동안 세션을 유지합니다. PDF는 PC의 output 폴더에 저장됩니다.
